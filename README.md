# Food Delivery Performance Analysis – Power BI

## 📊 Project Overview

This project analyzes food delivery performance using Microsoft Power BI.

The dashboard compares current-period and previous-period performance across:

- Order volume
- Revenue
- Average Order Value (AOV)
- Discounts
- Profitability
- Payment methods
- Order value buckets

## 🛠️ Tools Used

- Microsoft Power BI
- DAX
- Power Query
- Data Visualization
- Business Intelligence

## 📈 Key KPIs

- Total Orders: 1,000
- Order Growth: -75.78%
- Revenue Growth: -75.52%
- AOV Growth: +1.07%
- Total Order Value: ₹1.05M
- Total Profit: -₹5.75K

## 🔍 Key Insights

- Order volume declined significantly compared with the previous period.
- Revenue declined by 75.52%.
- AOV increased slightly by 1.07%.
- The ₹800+ order-value segment contributed approximately 85% of total order value.
- Overall profitability remained negative.
